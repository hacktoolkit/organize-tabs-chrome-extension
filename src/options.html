Duplicate rules

A rule turns many URLs into one key. Tabs with the same key are duplicates, and "Close Tabs Like This One" can close every tab matching a rule. match is a regular expression tested against the full URL and key is a template where $1…$9 or ${name} insert capture groups.

Rules from the remote file

Read-only. A local rule with the same name overrides a remote one.

Sync & backup

Settings and rules are saved to your browser profile's sync storage, so they follow you to every machine signed into the same Chrome or Brave profile.

Export and import

Move settings between profiles that do not sync with each other, or keep a copy in your dotfiles.

Or paste JSON here

Remote rules file

Point at a JSON file you host, for example a raw file in a dotfiles repo or a gist. Its rules are merged in after your local rules and refreshed on a schedule. The file must be reachable without login.
